## Acceptance items
1. `start/3` validates options like `Query.execute/3` and rejects before spawning: **done**.
2. Frames arrive in stream order, and the docs state the policy for a slow owner: **done**. Delivery is unacknowledged; once the owner's mailbox holds 1,000 messages (configurable), further frames are dropped and counted in the snapshot.
3. `snapshot/1` does not block on the child: **done**.
4. `await/2` returns the same result and error types plus exactly one evidence record, and its timeout does not cancel the run: **done**.
5. `cancel/2` is idempotent, records the cancellation, and reports the runner's cleanup facts: **done, with a limit**. Forcola 0.7 has no way to cancel a run and get a report back. Cancelling closes the port Forcola owns, Forcola kills the process group, and nothing more comes back. So the evidence always says cleanup is unknown, and `cancel/2` can return before cleanup has finished. The PR body says this.
6. Owner exit cancels the run: **done**.
7. Fake-executable tests for success, failure, timeout, cancel before and after output, and owner exit: **done**. They run the real Forcola runner against shell-script fakes, in `test/claude_wrapper/run_test.exs`.

## Things I'm unsure about
- `start/3` returns once the run has started, not once the child process exists, because runners don't report when they spawn. The issue says "once the child is spawned". A spawn failure the runner reports comes back through `await/2`.
- I extended the public runner behaviour to support this:
  - the runner now gets a cancel reference in `opts[:cancel]`;
  - there is a new optional `check_evidenced/2` callback;
  - there are new error kinds `:cancelled` and `:invalid_run_options`;
  - there is a new evidence reason `:cancelled`.
- The run process keeps the outcome until the owner exits. A long-lived owner that starts many runs keeps one finished process per run until then.
- The cancel-then-unterminated-event test waits a fixed 200 ms after the child writes its pid. It passed in every run, but it depends on timing.
