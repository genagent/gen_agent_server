# Ensemble fix runs: Debate #212 and Consensus #209

Both issues were claimed with `status/in-progress` after checking for overlapping pull requests. Two isolated clean clones of `gen_agent` main at `7f848d4` were used. The reusable [control script](issue_handoff_used.exs) ran named GenAgent Server triage, implementation, and review stages, retained stage metadata and exact prompts, and stopped each instance. The issue text, constraints, configuration, stage outputs and diff patches are in the `debate/` and `consensus/` directories. Two instances ran concurrently, below the three-worker limit. The caller independently ran tests and quality checks; model review was not treated as a substitute for those checks.

Debate #212 used Codex `gpt-6-luna` for triage, Claude `claude-haiku-4-5-20251001` for implementation, and Codex `gpt-6-luna` for review. The review approved. The caller removed an unused field and replaced a race-prone integration test with a deterministic strategy callback test for queued topics. The final diff retains the original prompt on each turn and labels the prior speaker. Sixteen focused Debate tests and the full 181-test Ensemble suite passed. Format, strict Credo, docs with warnings as errors, and diff check passed. Unrelated lockfile drift from dependency resolution was restored.

Consensus #209 used Codex `gpt-6-astra` for triage and review and Claude `claude-sonnet-5-5` for implementation. Review round 1 requested changes to a round-reset test, first-error ordering, and tests with uncontrolled completion order. The `revise` path resumed the implementation session and reran review; round 2 approved. The final diff requires a unique leader at threshold and tolerates turn errors while the original threshold remains attainable. Twenty-eight focused Consensus tests and the full 192-test Ensemble suite passed. Strict Credo, docs with warnings as errors, and diff check passed. The first CI run caught a missing format pass; the caller ran `mix format`, pushed a formatting-only commit, and awaited the rerun. Unrelated lockfile drift was restored.

The fixed stage templates are useful for simple isolated fixes. The Consensus revision demonstrates the need to preserve reviewer feedback and the implementation session across rounds, while separately enforcing host-run tests. The caller tightened a post-review Debate test; future control code should trigger a final review when the caller edits an implementation after the model review.
