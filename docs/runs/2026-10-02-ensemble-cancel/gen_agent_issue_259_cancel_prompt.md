# Second slice of genagent/gen_agent#259: cancel an Ensemble token

The first slice (merged as gen_agent PR #337) added completion messages and event-driven await. Add token-scoped cancellation without stopping the Ensemble session or unrelated tokens. A successful cancellation closes the pending token with `{:error, :cancelled}` through the existing reply path so tell completion recipients, await waiters, and any blocked ask caller receive one terminal outcome; the late child completion must not be assigned to another token. The API should return a clear success or already-finished/not-found/unsupported result.

Use core `GenAgent.cancel_request/3` for queued child refs and `GenAgent.interrupt_request/3` for a matching current ref. This is a BEAM/request acknowledgement, not proof that an external provider process has settled. The framework knows child refs in `in_flight`; built-in strategies must remove or advance their own token state. A custom strategy without the new optional cancellation callback must reject cancellation rather than corrupt its queue. Include deterministic tests for Solo, Switchboard, Pool, and one multi-agent pattern, including queued versus active requests, late completion, duplicate cancel, and preservation of other tokens. Do not implement stream forwarding here; core #106 is its prerequisite. Keep #259 open.
