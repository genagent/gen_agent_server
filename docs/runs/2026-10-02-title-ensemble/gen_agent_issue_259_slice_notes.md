Design constraint: GenAgentEnsemble.Server owns token lifecycle. Completion recipients are PIDs validated at the API boundary. A terminal notification must be emitted exactly once when `reply_to_token` closes a pending tell token, including errors from rejected dispatch and halt. It must not consume or change stored results. `await` should be implemented as event-driven server state, without polling or sleeping. A timeout must not consume the eventual result or leave a stale waiter; late terminal results may still be polled. Clarify how simultaneous waiters and `poll` interact. Keep timer/monitor cleanup bounded. Tests should use controlled/mock backends, not wall-clock sleeps. Do not edit generated release files or unrelated modules.
